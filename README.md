# crush-light

> [!WARNING]
> This is a mostly vibe-coded project. Proceed with appropriate expectations.

crush-light is a stripped-down fork of [Crush](https://github.com/charmbracelet/crush) by Charmbracelet. The goal is simple: rip out everything we don't need — MCP, LSP, sub-agents, analytics, and other features — leaving behind a leaner, focused terminal AI coding assistant.
